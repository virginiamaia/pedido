# Brenda & Virgínia — Nossa história

Site interativo em HTML, CSS e JavaScript puro, com personagens em pixel art.

## Como abrir
- Extraia o ZIP.
- Abra a pasta no VS Code.
- Abra `index.html` com a extensão Live Server (ou diretamente no navegador).

## Personalização
- Os retratos sem plaquinhas com nomes ficam em `assets/brenda-character.png` e `assets/virginia-character.png`.
- Os cenários ficam na pasta `assets/`.
- Os textos e capítulos podem ser alterados diretamente em `index.html`.
- A trilha sonora é sintetizada no navegador com Web Audio API e começa após interação da visitante.

As personagens permanecem paradas; foram removidas as animações de caminhada.


## Música romântica
O capítulo final incorpora o player oficial do Spotify para “5 Km - Ao Vivo”, de Henrique & Juliano. A visitante precisa tocar em play no player; o Spotify pode solicitar login e não garante reprodução automática. A trilha de suspense continua sendo sintetizada localmente no navegador.
